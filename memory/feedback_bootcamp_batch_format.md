2026-08-22, after a 5-run dinner batch delivered as a digest: "I am
impressed with your speed, but do want to keep the same format instead of
shortened when you are doing batches."

**Why:** the verdict format (anybody test · data table · event test ·
grade + miss ledger · why-pass pairs) IS the deliverable — a digest hides
exactly the misses the grade exists to surface, and the user reads these
for learning, not just status.

**How to apply:** in `/bootcamp N` or auto mode, every run gets the
complete verdict block at delivery. One-line Run Log notes are progress
tracking during the batch only. Recorded in [[project-decoder-bootcamp]]'s
Bootcamp.md (P-5 render rule) and the bootcamp SKILL.md.
