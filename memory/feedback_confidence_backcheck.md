Track confidence per conclusion, and when a new problem/trap/variant is
discovered mid-stream, immediately go back and test every earlier entry against
it. Do not assume prior work is safe because it "passed" — it passed a check
that predates the lesson.

**Why:** learning arrives in the middle of a run. Entries 1–11 were judged by
the rules known at entry 1. The trap found at entry 12 was invisible earlier by
definition, so the earlier entries look *cleanest* exactly where they are most
likely wrong. This is the same mechanism as [[feedback_bkrea_scale_failure]]
(large N hides bugs) but on the time axis instead of the volume axis: early N
hides the bugs that later N teaches you to see.

**How to apply:**
- Keep a running trap list per project (ACRIS: placeholder pages, index
  under-reporting rosters, consideration hidden in prepaid-tax reference
  numbers, appended unexecuted form copies, quantity-unstated instruments,
  condo unit-lots as the actual grantor, collective grants with no per-lot
  split, retired-lot lineage). Every new trap is appended, never just fixed
  forward.
- On each new trap: re-check ALL prior entries, and say plainly what the
  re-check found — including "no change." A backward sweep that reports
  nothing is still a result.
- "I already verified that" is insufficient if the verification predates the
  lesson. Re-verify against the new rule specifically.
- State confidence honestly per conclusion (verified by arithmetic / verified
  by external source / inferred / assumed) so the weak ones are findable later.

**ITERATIVE ENGINE — standing authorization (granted 2026-08-05):** run the
crawl → walk → jog → run ladder autonomously, without asking permission at each
rung. On every fall (a failed check, a new variant, a wrong assumption): stop,
learn the rule, go back to the START, and re-run the whole ladder — including
re-testing every earlier entry against the new rule. Keep looping until a full
pass produces no new falls. Only then scale up. Do not present a rung as passed
because nothing obvious broke; a rung passes when the specific traps known at
that moment have all been re-run against it and reported with denominators.
