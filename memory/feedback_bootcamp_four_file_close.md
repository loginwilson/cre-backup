2026-08-22: "it's very important that graded filings are recorded so each
bootcamp is improved upon." An audit at run 36 found the record complete
but NOT CONSULTABLE — Draw Board unmarked since run 32 (would have
re-offered four drawn docs), no Lexicon despite the Context Line
depending on one, and every graded miss sitting in prose inside a
5,400-line file where recurrence was invisible.

**Why:** that invisibility is exactly how the motive-claim defect reached
a FOURTH occurrence. A grade that cannot be consulted across runs cannot
improve the next one.

**How to apply:** a run closes only when four files are written —
`Bootcamp.md` (entry + law), `Run Log.md` (stamp), `Grade Ledger.md`
(miss BY CLASS + where the fix landed), `Draw Board.md` (drawn doc marked
off, same commit). Plus `Lexicon.md` when a document teaches a
class-level term, `Compose Card.md` when the fix is compose-time.
At grading, READ the Grade Ledger first: name the CLASS, grade harder on
repeats, and treat any class reaching 3+ rows as a MISSING STRUCTURE —
change the shape rather than write another rule (that is what produced
the trigger list). All under `D:\CRE Decoding System\Bootcamp\`.
