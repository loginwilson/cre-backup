# OVERVIEW

**TABLE CHANGE 2026-08-20 (Bootcamp r49):** event rows carry `doc_type` in
PROVENANCE. For this phase, one new grouping dimension: doc_type x function
= the measured type->function ledger; chains built on counted pairings, and
a tripwire for source mislabels. Details in the source md.

Resolution turns events into CHAINS and ACCOUNTS — one event graph per key,
traversed by time and by function (and later by party, by development, by
whatever a new context needs: new traversals are new groupings, never new
machinery). **This is the convergence phase:** upstream, every source ran in
its own lane; here their events pour into the SAME graph, joined by the
shared key space (01's rule) and the shared event grammar (03's rule). A
parcel's chain holds its deeds and — when DOB joins — its permits, in one
story that no longer remembers which source told it. The MERGED graph is
owned at THIS level; each source md owns only its source-specific grammar
(what a satisfaction must find, what a permit must reference).

# 1 · OUTPUT — the converged product

Per key: the time chain, the function chains, the accounts (always the sum
of their chains), and the written chain (generated from the data track,
never authored free-hand) — across ALL sources' events at once. Every event
ends chained, parked, unattachable, or defect; every break carries a name.

# 3 · CHECK

The phase is level when every key's events — from every source — conclude
in a state, every chain closes or carries a named break, every account
equals its chain, and every cross-source join can show its justification
(the bridge audit). Cross-source contradictions (two sources implying
different owners at one date) are NAMED BREAKS with both traces shown —
never silently arbitrated.
