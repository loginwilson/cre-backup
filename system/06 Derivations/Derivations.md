# 1 · OUTPUT — the converged product

**One present state per key, one question registry, all sources.** The
registry is phase property: every question is a row (inputs · rule · output ·
applicable keys · REQUIRED SOURCES). Questions answerable from live sources
answer now; the rest sit `partial — source named` and light up the day their
source joins — which makes the registry double as the SOURCE ROADMAP: the
most-wanted partials are the argument for the next source. Alongside the
answers: the metrics (stored formulas, never stored truths), the macro
summaries (generated, never free-hand), and the signals (the inference tier,
always labeled — facts record, signals think).

# 3 · CHECK

The phase is level when every key's applicable registry rows conclude
(answered / partial-source-named / blocked-break-named), every answer walks
its trace, every metric recomputes, no signal sits where a fact belongs, and
every as-of stamp matches a proven sync level. This check gates the PRODUCT:
a failing answer is withdrawn from the surface.
