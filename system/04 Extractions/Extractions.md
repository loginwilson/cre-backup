Extraction turns acquired documents into EVENTS — the first analytical
phase, and the start of sanitization (extraction → resolution → derivation).
Because the work is judgment, not procedure, every source here carries TWO
layers: the md (the constitution) and a BOOTCAMP (the earned learning), built
in a bootcamp before production runs at scale.

# 1 · OUTPUT — the converged product

**Every source's events land in the SAME EVENT GRAMMAR:** subject × function
× mode + quantity + term, N-legged, anchored to document + page, with an
event summary per document. That shared grammar is THE convergence rule of
this phase — a deed's transfer and a permit's filing must be the same KIND
of thing, or Resolution can never chain them into one story. Grammar is
system property; no source invents its own event shape. (Events are not only
transactions: regulatory events enter by applicability — the grammar holds.)

# 3 · CHECK

The phase is level when every source's exact sum closes over its handed-off
population and its anchor audit is clean. Grammar conformance is audited at
THIS level: an event that fits no slot of the shared grammar is a
source-level defect, not a new column.
