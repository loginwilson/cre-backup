# OVERVIEW

Navigation turns named doc ids into THE MAP — one row per document:
**key · doc id · index details · endpoint**. It is the only phase that
writes the map. Two modes per source (backfill builds, sync keeps level),
and the endpoint column is the whole point downstream: it is what
Acquisitions walks.

# 1 · OUTPUT — the converged product

One map per source — **all keyed into the SAME KEY SPACE.** That shared key
space (parcel BBLs, lineage edges, canonical parties) is THE convergence
rule of this phase: a Legal Instruments deed and a future DOB permit on the
same lot must carry the same key, or nothing downstream can ever join them.
The key space is system property; no source invents its own.

universal: **every doc id in every source keyed to 0 left.** Key integrity
(reachable-by-nothing = 0, dangling lineage = 0) holds across the shared key
space, not just within one source.
