## 3 · RESOLUTION

**1 · The subject conflict — resolved on geometry, not on votes.**

| claim | source | verdict |
|---|---|---|
| Parcel I = Block **1206** Lot 1 | cover, title page p003 | **accepted** |
| Parcel I = Block **1201** Lot 1 | Exhibit A p022, **pixel-confirmed** | **rejected — scrivener's error** |

Parcel I runs 125' east from the Columbus Avenue corner; Parcel II *begins* 125' east of the
same corner. **They abut.** One instrument cannot describe two abutting parcels on two
different blocks. ⚠ The rejected claim stays attached — the error is really on the paper.

**2 · Four claim-events collapse to ONE.** They share one date, one instrument, one set of
parties, one subject, and **one cap** (§34 caps everything secured *under any contingency*).
Posting them separately books **$49.6M against a $16.5M loan.**

**3 · One event, two parcels, and the amount does not divide.**

| posting | result |
|---|---|
| full amount to each | $33.1M on one block — **double-counts** |
| 8,269,192.19 each | a split the instrument never makes — **invents a number** |
| first-named lot only | Lot 45 reads unencumbered — **loses the lien** |
| **full to both, marked shared** | **correct** |

Joint and several, cross-collateralized, one cap. Each parcel genuinely stands behind the
whole amount — that is what a foreclosure would do.

**4 · The mortgagee resolves to an AGENT, not a creditor.** *"as administrative agent for
the Lenders"*; the Lenders are never named in 22 pages. §21 lets Capital One assign *"to any
successor administrative agent."* Resolving it as *the lender* makes a routine agent swap
read as a debt sale.

**5 · Event dates at RECORDING** (2016-08-23) for priority; executed 2016-08-03 binds the
parties. Neither is the document-ID date.

## 5 · RULES LEARNED

### CODE

| rule | check |
|---|---|
| **Never date an event from the document ID** | ID prefix `20160818` vs recorded `2016-08-23` |
| **Ceiling ≠ balance** | `"up to"` / `"maximum amount … secured"` → `bound: upper`, and the account carries a ceiling with **no balance** |
| **Collapse events sharing one cap** | same date + parties + subject + cap ⇒ one event. Prevents 3× counting |
| **Cross-collateral posting** | multi-parcel + joint & several ⇒ full amount to each, flagged `shared`, **never summed** |
| **Account stays open on evidence** | only recordable exits ⇒ no decay, no expiry |

### MODEL

- **The operative clause locates the event; covenants and recitals are terms.** 35 sections
  produced 3 events.
- **A boilerplate mention is not an event.** Clause (a) sweeps in *"air rights and
  development rights"* as collateral — a keyword reader fires ENVELOPE. There is **no SF
  quantity in 22 pages.** The quantity decides, not the noun.
- **Cross-collateralization has no clause.** It is structural — two borrowers, joint and
  several, two parcels, one cap. Only readable from the *shape* of the grant, and it is the
  most consequential term in the document for valuing either lot.
- **`as administrative agent` ⇒ role AGENT, principal absent.** Same shape as MERS-as-nominee.

### HUMAN

- A legal description contradicting the cover on the block number. Pixel-verified, then
  resolved on the metes-and-bounds geometry. **Had this been keyed on Exhibit A alone — the
  "authoritative" legal description — the lien would have landed on the wrong block, and a
  stranger on Block 1201 would carry a phantom $16.5M lien.**
